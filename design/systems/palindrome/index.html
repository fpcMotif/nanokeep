nanokeep · Design system for macOS

Every number
has a partner.

Palindrome dresses nanokeep in the clothes of a Mac app: SF Pro, glass sidebars, capsule toolbars, sheets and system colours. It keeps one idea of its own. Paired values meet at a spine.

Two rules we break

Everything else follows the Human Interface Guidelines. These two breaks give nanokeep its own face. Each one is limited so that it never fights the platform.

Break one

The spine runs through the data.

macOS tables keep each metric in its own column. nanokeep puts CPU and memory into one cell, and they grow away from a thin accent axis. Only data cells carry the spine. Chrome never does.

Break two

Hero numerals, set in SF Pro Rounded.

Mac apps rarely open a pane with a giant number. nanokeep does, once per pane, in SF Pro Rounded at 42 pt or larger. It is the number you came to read, so it gets the room.

Colour

The accent is a deep violet, close to systemPurple. Memory and download use a warm sand. Upload and reclaimed space use a soft lime. Window materials are standard macOS greys, with a faint violet tint in the glass.

Type

The system font everywhere. Tabular figures on every number. SF Mono only for paths, ports and PIDs a person might copy.

Controls

Native shapes from macOS Tahoe: capsule toolbar groups, pill segmented controls and full-round buttons. One prominent button per view.
