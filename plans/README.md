## Findings considered and rejected

- Callbacks queued on the main thread outliving their owners at shutdown: not verified, it depends on how nanoui drains its queue.
- `CFBundleExecutable` joined into a path (`src/apps.zig:172-176`): the app only reads a Mach-O header, so the impact is negligible.
- Faster search: a keystroke takes 0.04 ms, 400 times shorter than one frame. Scoring each distinct name once would save about 40% of that.
- Merging the two system readers (`src/procs.zig:327`, `src/metrics.zig:311`), reusing the network buffer (`src/metrics.zig:277-279`) and caching IOKit key strings: each saves microseconds per sample.
- A kernel event source for process exit: plan 008 checks 10 times a second for 5 seconds instead, which tests can drive.
- Skipping the per-process sample while hidden: it costs about 4 ms every 10 seconds and feeds the usage ledger.
- The "nothing can call Spotlight" test inspects the test binary (`src/tests.zig:360-368`): a best-effort guard, minor.
- Ad-hoc code signing causing repeated Full Disk Access prompts (`build.zig:39`): not verified.
